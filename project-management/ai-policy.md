# AI Policy

Document how your team will use AI on the Team Project, within the course's Team Project AI rules.  Your policy may be stricter than those rules, but not looser.  Bring what each of you learned in your Onboarding Project Milestone 7 retrospective.  Revisit this policy at your team check-ins and update it when something isn't working.

## Use for Code and Tests

Where does your team want AI involved?  Generating test cases, scaffolding a component, explaining unfamiliar code, and writing production logic are very different decisions.  Say which are in and which are out.

- We don't mind AI assisted work in generating test cases, scaffolding a component, explaining unfamiliar code, and writing production logic as long as the work is clearly documented and AI work is acknowledged. Additionally, prompter should be able to explain their code without AI assistance on their generated code.

## Review Expectations

How does AI-generated code get reviewed before it merges?  The person who prompted may not be the only reviewer.  What else does your team require?

- Mention at the top of every file who authored the file
- Follow GitHub PR processes to review AI code before it's merged i.e. person who prompted cannot be review, person who open PR cannot be closing PR

## Acknowledgment

Pick **one** way to mark AI-assisted work: a note in the pull request description, a commit trailer, or a code comment.

- Code comment when using AI assisted work

## What "Verified" Means

Before AI-assisted code is merged, what has its author actually done?  Run it, read it line by line, written a test that fails without it?

- Author should read line by line to make sure code has intended function. Make sure that they can explain the code. 
- Author should be able to explain AI tests written for that code.
- Don't push code where tests are failing. 

## Other Decisions

Optional, but worth deciding: how you'll use AI review of technical documents and who decides which suggestions to take; how you'll divide work fairly if a teammate opts out of AI; how you'll count AI-assisted output toward contribution; how long to iterate on a prompt before writing it yourself; and whether you'll share prompts that worked.

- Avoid using AI for technical documents and consult the team with suggestions on design
- 5 prompts before doing the work myself.
- Share prompts that worked with the team
